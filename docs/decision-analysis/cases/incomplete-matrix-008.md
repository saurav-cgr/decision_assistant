# Case 8: Incomplete Score Matrix — Synthetic Rejection Test

**Status:** Negative validation test. This request must fail; it is not a decision recommendation.

## Purpose

Confirm that the API refuses to rank options when an option/criterion score cell is missing. Missing values must not be silently assumed, interpolated, or generated by an LLM.

## Intended defect

Two options and two criteria require four score rows. This request provides only three rows; `option_b` has no `quality` score.

## API request

```json
{
  "title": "Reject incomplete decision matrix",
  "options": [
    {"id": "option_a", "label": "Option A"},
    {"id": "option_b", "label": "Option B"}
  ],
  "criteria": [
    {"id": "cost", "label": "Cost", "direction": "cost", "weight": "0.5", "scale": "numeric"},
    {"id": "quality", "label": "Quality", "direction": "benefit", "weight": "0.5", "scale": "ordinal"}
  ],
  "scores": [
    {"option_id": "option_a", "criterion_id": "cost", "value": "100", "provenance": "user_provided"},
    {"option_id": "option_a", "criterion_id": "quality", "value": "4", "provenance": "user_provided"},
    {"option_id": "option_b", "criterion_id": "cost", "value": "80", "provenance": "user_provided"}
  ]
}
```

## Expected result

```text
HTTP 422
code = validation_error
message = Request validation failed
```

The detailed validation error must state that every option/criterion score pair is required.

## Pass criteria

- No ranking is returned.
- No total scores are calculated.
- No narrative request is sent.
- Client must require missing input before resubmission.
